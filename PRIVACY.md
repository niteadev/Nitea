# Privacy Policy for Nitea

*Last updated: August 14, 2026*

Nitea ("the Application", "we", "us", or "our") is committed to protecting your privacy. This Privacy Policy explains our practices regarding data collection and usage.

## 1. Zero Data Collection

Nitea does **not** collect, store, transmit, track, or share any personally identifiable information (PII) or user data of any kind. 

- **No Account Required**: You can use Nitea without creating an account or providing personal details.
- **No Analytics / Telemetry**: The application does not contain tracking scripts, behavioral analytics, or advertising telemetry.
- **No Background Surveillance**: Nitea does not monitor, log, or record your keystrokes, applications, or personal files.

## 2. Local Storage

All user settings, timer preferences, and interface configurations (such as selected language, timer durations, strict mode toggles, and UI themes) are stored strictly locally on your device via standard local storage mechanisms. None of this data is ever transmitted to external servers.

## 3. Network Communications

The Application makes network requests exclusively for the following optional, non-identifiable purposes:
- **Software Updates**: Checking for application updates via GitHub Releases.
- **Localization**: Fetching updated locale string files for translations.
- **Promotional Info (AppBox)**: Retrieving public announcement/promotional cards when connected to the internet.

No personal identifiers or telemetry payloads are sent during these network requests.

## 4. Third-Party Services

Nitea does not integrate with any third-party advertising networks, data brokers, or profiling services.

## 5. Changes to This Policy

We may update our Privacy Policy occasionally. Any changes will be posted on this page with an updated revision date.
